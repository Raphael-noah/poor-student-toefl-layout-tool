# 命苦工具之排版托福PDF

这是命苦的我被老师要求搞排版太费劲做的。

将托福阅读真题 PDF 按“文章 + 题目”自动拆分。
- 支持跨页自动拼接          
- 自动过滤水印              
- 自动识别参考答案并单独打包

> ⚠️ **注意**：本脚本高度定制化，包含大量特定正则和行距切断逻辑，仅针对特定排版的《托福阅读真题》PDF 有效。

## 使用方法                                             
```bash
python3 split_toefl.py "托福阅读.pdf" -o output_articles
```
